# 🚀 Интегратор актуальных цен
Программа-интегратор предназначена для мониторинга текущей стоимости одного конкретного товара на различных маркетплейсах и в сетях магазинов. Главная задача проекта — предоставить пользователю моментальный срез цен с возможностью выбора площадки, не перегружая систему сбором исторической динамики и графиками.

## 🛠 Стек технологий
Поскольку задача сводится к сбору данных без сложной аналитики, стек можно оптимизировать под скорость разработки:
 * **Язык:** Python (идеален для написания парсеров с использованием BeautifulSoup, requests или Selenium).
 * **База данных:** SQLite или легковесное хранение в JSON. Так как динамика цен не отслеживается, разворачивать тяжелые PostgreSQL или MySQL нет необходимости.
 * **Инструменты проектирования:** Draw.io / PlantUML.
